# roblox-flick-flock
아들과 만드는 로블록스 게임

설계서: [FLICK_FLOCK_DESIGN.md](FLICK_FLOCK_DESIGN.md)

## 실행하기 (Windows)

1. [Git](https://git-scm.com/download/win)과 Roblox Studio를 설치합니다.
2. `open-studio.bat`을 바탕화면에 복사해 두고 더블클릭합니다.
   - 처음엔 `%USERPROFILE%\roblox-flick-flock`에 레포를 받고, 이후엔 실행할 때마다 `git pull` 합니다.
   - Rojo를 받아 Studio 플러그인을 설치하고, `FlickFlock.rbxlx`를 만들어 Studio로 연 뒤 Rojo 서버를 켭니다.
3. Studio 로그인 계정이 `oompaloompa0730`인지 확인합니다 (한 번 로그인하면 기억됨).
4. Studio에서 **플러그인 탭 → Rojo → Connect** (`localhost`, 포트 **34872**).
5. **Play** 를 누르면 혼자서 빨강·파랑을 번갈아 조종합니다. 둘이 하려면 **Test → Clients and Servers → 2 Players**.
